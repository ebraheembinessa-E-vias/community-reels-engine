- 2026-09-22, the same real run, two more findings fixed in the engine: (1) Gemini wrote every time after the first minute as minutes-and-seconds without the colon (1:03.0 as `103.0`) although the prompt asks for seconds; the draft plan would have failed validation or cut the wrong places. `normalize_times` now reads a whole report in that mode when it holds such values and none between 60 and 100. What the assistant still had to do by hand: split the draft's keep spans around pauses longer than a second (the engine does not tighten silences inside a kept span), move four draft boundaries that sat inside speech onto measured dips of the waveform, and clamp captions that overhung a cut by the model's half-second granularity.

- 2026-09-22, the same real run, the render stage: four more engine fixes. (2) The masthead draws above the footage. (3) A caption's Latin islands are runs of one caption; the layout check measured two of them as separate blocks and reported an overlap where the caption wrapped, so the islands never break across lines and carry the check's own allow-overlap mark. (4) Captions over 60 characters step down one size. The take then rendered through the ordinary road: 92.6 s, 1080x1920, decoded audio equal to the approved clean master, HyperFrames check clean of errors with its structural advisories kept in check.json. ## Scope limits

The bundled demos contain no speech. They verify the media and animation path, not transcription quality or creative judgement. A real creator must still review spoken transcript accuracy, edit boundaries, visual meaning and the finished playback.

Live Gemini key/model discovery and token counting worked. The source-analysis run encountered repeated provider HTTP 503 errors on both Pro and Flash. One Pro request returned a single-object-array response that an earlier parser discarded; the adapter was corrected and now persists raw payloads and accepts that wrapper. A complete live Gemini-to-finished-spoken-reel path is still pending, so this is a release candidate, not a claimed production-certified engine.

Linux and Windows have not been tested. The encoder avoids Apple-only APIs and the font is portable, but that does not establish cross-platform support. Dependencies may download Chrome and additional font resources on first use; no API key is needed for that local sample.
